# py-sandbox

The Python component of the Wasm code sandbox. It executes untrusted, AI-generated
Python received as a JSON envelope on `POST /py/...`, compiled to WebAssembly with
[`componentize-py`](https://pypi.org/project/componentize-py/) (CPython 3.12 →
`wasm32-wasi`, Spin Python SDK 3.4.1 for Spin 3.x / WASI Preview 2).

See the [top-level README](../README.md) for the request/response contract, the
security model, and the full list of pre-installed dependencies.

## Build

```bash
bash build.sh            # or, from the repo root: spin up --build
```

`build.sh` creates an isolated python3.12 venv with the pinned build tools
(`spin-sdk`, `componentize-py` — see `requirements.txt`), populates `vendor/` with the
runtime dependencies via `setup-vendor.sh`, then runs `componentize-py` to produce
`app.wasm`.

`vendor/` and `.venv/` are git-ignored and fully regenerated by the build.
`setup-vendor.sh` copies prebuilt `wasm32-wasi` packages from the `spin-python-deps` git
submodule in this directory (run `git submodule update --init` if `py-sandbox/spin-python-deps`
is empty) and pip-installs the pure-python deps from `vendor-requirements.txt`. Override the
location with `SPIN_PYTHON_DEPS` if needed.
